# Emoji V7 Assets

Public assets repository for emoji_v7 LINE Bot game.

## Structure

```
images/
  ├── icons/       # Game icons
  ├── ui/          # UI elements
  ├── monsters/    # Monster images
  └── items/       # Item images
```

## Usage

Raw URL format:
```
https://raw.githubusercontent.com/yipenglemon/emoji_v7_assets/main/images/{path}
```

Example:
```javascript
{
  type: 'image',
  url: 'https://raw.githubusercontent.com/yipenglemon/emoji_v7_assets/main/images/ui/banner.png',
  size: 'full'
}
```
